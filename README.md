# MKTECH Automação Residencial

Site de uma página. Abra `index.html` ou publique pelo GitHub Pages (Settings > Pages > Deploy from a branch > main / root).

Antes de publicar, troque o número do WhatsApp na última linha do `index.html` (variável `WHATSAPP`, formato 5534984094453).

## Arquivos

- `index.html`: versão atual, no modelo da DUXOR com a identidade da MKTECH.
- `versao-anterior.html`: site completo anterior (fotos, cenas interativas), guardado como backup.
